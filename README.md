# Research

Security tools from Justivia Legal Ventures LLP.

- **[phishguard/](phishguard/)**: link and sender checks for phishing and smishing.
  Extracts URLs, checks them against Google Safe Browsing, OpenPhish and URLhaus,
  flags lookalike and newly registered domains, and reads SPF, DKIM and DMARC
  results into one verdict.
- **QSign**, a quantum-safe e-signature platform for AWS: see the open pull request for the first version.
